# 📰 Fake Headline Generator

A simple Python project that generates random fake news headlines by combining predefined words and headline templates.

## 📌 Features

- Generate random news-style headlines
- Simple and beginner-friendly Python project
- Lightweight and easy to understand
- Easy to customize with your own words and templates

## 🛠️ Technologies Used

- Python 3

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/dhurbasikdar/Fake-Headline-Generator.git
```

2. Navigate to the project directory:

```bash
cd Fake-Headline-Generator
```

3. Run the Python file:

```bash
python main.py
```

## 💡 Example Output

```text
Breaking News: Virat Kohli Declare's War On during IPL match

Auto Riskshaw From Delhi Lanches at red fort

Virat Kohli Celebrates a plot of samosa
```

This project was created to practice Python programming concepts such as variables, lists, functions, randomization, and string formatting while building a fun and creative application.
